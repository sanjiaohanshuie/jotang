## 学习笔记

### 已掌握的Git操作

1. 在GitHub网页创建公开仓库

2. `git init`：本地初始化仓库

3. `git add .`：把文件加入暂存区

4. `git commit -m "描述信息"`：提交到本地仓库，规范填写commit message

5. `git remote add origin`：关联远程GitHub仓库

6. `git push -u origin main`：将本地提交推送到远端仓库

7. `git pull`：拉取远程仓库最新代码并合并

8. 了解 Fork、Pull Request 的协作流程

9. 使用 SourceTree 图形化工具可视化操作Git
